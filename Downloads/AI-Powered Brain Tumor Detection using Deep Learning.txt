# Image Preprocessing

Image preprocessing is one of the most important steps in any Deep Learning project.

Before training a model, all images should have the same size and similar pixel value range. Neural networks cannot efficiently learn from images having different dimensions and unnormalized pixel values.

In this phase, we will:

- Resize all images to a fixed size.
- Normalize pixel values.
- Create TensorFlow datasets for model training.

These preprocessing steps improve training stability, reduce computational complexity and help the model learn better.

## Why Resize Images?

Images in real-world datasets may have different dimensions.

Deep Learning models require every image to have the same input size. Therefore, all MRI images will be resized to **224 × 224 pixels** before training.

224 × 224 is one of the most commonly used input sizes for pretrained models such as EfficientNet, ResNet and MobileNet.


## Step 1 - Define Image Size

```python
IMAGE_SIZE = (224, 224)
```

All images are resized to 224 × 224 pixels before training.

### Why?

Images in a dataset may have different dimensions. Deep Learning models require all input images to have the same size. Using a fixed image size makes the training process consistent.

We selected 224 × 224 because it is the standard input size used by many pretrained models such as EfficientNet, ResNet and MobileNet.

---

## Step 2 - Define Batch Size

```python
BATCH_SIZE = 32
```

Batch size defines how many images are processed together in one iteration.

Instead of loading the complete dataset into memory, TensorFlow divides the dataset into small batches.

### Benefits

- Reduces memory usage.
- Makes training faster.
- Better GPU utilization.
- Stable gradient updates.

---

## Step 3 - Create Training Dataset

```python
train_dataset = tf.keras.utils.image_dataset_from_directory(
    train_path,
    image_size=IMAGE_SIZE,
    batch_size=BATCH_SIZE,
    shuffle=True
)
```

This function automatically performs several tasks:

- Reads all images from the Training folder.
- Reads folder names and creates labels.
- Resizes every image to 224 × 224.
- Groups images into batches.
- Creates a TensorFlow Dataset object.

### Parameters

train_path

Specifies the location of the training dataset.

image_size

Defines the output image size after resizing.

batch_size

Defines how many images are loaded together during one iteration.

shuffle=True

Randomly shuffles training images before every epoch. This prevents the model from learning the order of the dataset and improves generalization.

---

## Step 4 - Create Testing Dataset

```python
test_dataset = tf.keras.utils.image_dataset_from_directory(
    test_path,
    image_size=IMAGE_SIZE,
    batch_size=BATCH_SIZE,
    shuffle=False
)
```

Testing images are not shuffled because evaluation should always happen in a fixed and consistent order.

## Class Names

TensorFlow automatically assigns labels to each class based on the folder names.

The `class_names` attribute helps us verify the detected classes and their order before training the model.

Knowing the class order is important because the model predicts class indices (0, 1, 2, 3), which are later mapped back to these class names.
